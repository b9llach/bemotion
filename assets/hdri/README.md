# Bundled HDRIs

Studio lighting environments from [Poly Haven](https://polyhaven.com/hdris), released under CC0 (public domain). No attribution required; credited here anyway.

| File | Source |
|---|---|
| `studio_small_09_1k.hdr` | https://polyhaven.com/a/studio_small_09 |
| `brown_photostudio_02_1k.hdr` | https://polyhaven.com/a/brown_photostudio_02 |

Use any Poly Haven HDRI in a spec with `"environment": "hdri:<id>"`. Ids that are not bundled are downloaded once into `~/.bemotion/hdri`. Browse with `bemotion hdri list`.
